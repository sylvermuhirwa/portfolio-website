A practical checklist for cleaning data

Sylver Muhirwa

Draft

Cleaning takes up much of the time in any analysis. A checklist keeps it consistent and repeatable.

Before you change anything

  • Save a copy of the raw data
  • Write down where the data came from and when

Check the basics

  • Count rows and columns
  • Count missing values in each column
  • Look for duplicate rows
  • Check that each column has the right type, such as numbers, dates or text

Fix inconsistencies

  • Make dates, units and spelling consistent
  • Check categories for variants of the same value
  • Look at the minimum and maximum of each numeric column

Before you move on

  • Look at outliers before deciding to remove them
  • Record every change you made
  • Save the cleaned data as a new file
