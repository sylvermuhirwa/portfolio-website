What data science taught me about asking better questions

Sylver Muhirwa

Draft

Most data projects go wrong before any code is written, because the question was unclear. Here is how I think about getting the question right first.

Start with the decision

Ask what decision the analysis will support. "What is happening to our sales?" is vague. "Should we stock more of this product next month?" points to the data you need.

Make it measurable

Turn the question into something you can count or compare, and say over what period and for which group of people.

Check that the data can answer it

Before analysing anything, ask whether the data actually covers the question. If it does not, say so early.

Accept "not enough data"

Sometimes the honest answer is that the data cannot support a conclusion yet. That is still a useful result.
